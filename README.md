# Travel Assistant — SnishStudio

Адаптивний сайт-помічник для планування подорожей. Підходить для публікації на **GitHub Pages**.

## Що є в проєкті

- Українська та англійська мови.
- Планувальник подорожей зі збереженням у браузері.
- Швидкі переходи до Kiwi.com, Omio, FlixBus та Google Maps.
- Калькулятор бюджету з категоріями витрат.
- Список речей із власними пунктами та індикатором готовності.
- Картки напрямків і корисні офіційні посилання.
- Адаптивний дизайн для телефонів, планшетів і комп'ютерів.

## Запуск локально

Найпростіше: відкрий `index.html` у браузері. Для локального сервера можна використати розширення Live Server у VS Code.

## Публікація через GitHub Pages

1. Створи новий репозиторій на GitHub, наприклад `travel-assistant`.
2. Завантаж **усі файли й папки** цього проєкту в корінь репозиторію.
3. Відкрий **Settings → Pages**.
4. У розділі Build and deployment вибери **Deploy from a branch**.
5. Вибери гілку `main` і папку `/ (root)`, натисни **Save**.
6. Зачекай, поки GitHub Pages опублікує сайт. Посилання буде приблизно таким:
   `https://ТВІЙ-НІК.github.io/travel-assistant/`

## Важливо про функції

Це статичний сайт без серверної частини та без платних API-ключів. Кнопки транспортних сервісів відкривають їхні сайти; вони не означають, що бронювання або оплата виконуються всередині Travel Assistant. Калькулятор бюджету використовує суми, які вводить користувач. Плани та позначки чекліста зберігаються локально в браузері й не синхронізуються між пристроями.

Перед поїздкою перевіряй актуальні тарифи, розклад, правила в'їзду та умови бронювання на офіційних сайтах.
